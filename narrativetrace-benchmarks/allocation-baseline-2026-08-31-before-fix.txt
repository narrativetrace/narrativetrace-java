# THE AGENT'S INACTIVE PATH IS NOT FREE, and this run is the first measurement
# that could say so about allocation. `AgentRuntime.enterMethod` builds a whole
# `MethodSignature` — two substrings off the qualified class name, a descriptor
# parse for the declared return type, the record itself — and only then calls
# `context.enterMethod`, which returns immediately at OFF. The proxy path asks
# `context.isActive()` first and builds nothing, which is why `proxy_OFF` costs
# 24 B and `agent_OFF` costs 392. Not fixed here: this run's scope is the ruled
# remedy set of the 2026-08-31 performance-regression analysis (private), and this is a new
# finding. It is why the README FAQ can no longer say the agent "adds nothing
# measurable". Recorded as open work, tracked privately.
#
